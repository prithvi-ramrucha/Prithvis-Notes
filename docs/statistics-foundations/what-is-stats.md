# What is Statistics?
Last Edited: 27/10/2026

### 1. The Dual Problem
Probability and statisics go hand-in-hand; like two sides on the same coin. Elegant theory to describe real world processes is given to us by probability, but statistics is the framework that we use to analyse and interpret the data produced by these processes. In other words, probability provides the theoretical model while statistics is used to fit the parameters of that model or to infer something about it. There is a dual problem:

- **(a)**. A model of the processes is created using probability theory using educated and appropriate assumptions.
- **(b)**. Statistics is used to fit (calculate the parameters of the model) and/or quantify the confidence we have in the model describing the process.
